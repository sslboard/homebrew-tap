# SSLBoard Homebrew tap

Homebrew casks for [SSLBoard](https://sslboard.com) tools.

## ctlog

List every hostname seen in Certificate Transparency logs for a domain.

```bash
brew install sslboard/tap/ctlog
```

Documentation: [sslboard.com/docs/ctlog](https://sslboard.com/docs/ctlog/). Source: [sslboard/ctlog](https://github.com/sslboard/ctlog).

The cask in `Casks/` is written by GoReleaser on each ctlog release. Don't edit it by hand: changes are overwritten by the next release.
